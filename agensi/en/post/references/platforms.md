# Platform rules

| | Facebook | LinkedIn | Instagram |
|---|---|---|---|
| Default limit | 1000 | 1300 | 1000 |
| Maximum limit | 3000 | 3000 | 2200 |
| Source link | full URL in the post | full URL in the post | **no URL in the post**; use a prompt such as "Link to the source in bio 👆" instead. The URL goes only into the sources section of the saved file |
| Hashtags | 3–5 at the end | 3–5 at the end | 8–15 in a separate block at the end, after a blank line |
| Emoji | 1–3 (expert), more (casual) | 1–2 at most, sparingly | more, as bullet markers |
| Tone | as in the profile | professional, substantive, few exclamation marks | relaxed, visual, direct |
| Opening | a catchy first sentence | the first 2 lines are the hook — only they show before "…see more" | the first sentence is the hook — it shows under the image |
| Extra | — | — | "Image idea": 1–3 sentences describing an image or carousel (what goes on each slide). Not part of the post text and not counted towards the limit |

Minimum limit for every platform: 200 characters.

Common to all platforms:
- no Markdown formatting (no `**`, no `#` headings, no `-` lists), paragraphs separated by a blank line,
- the **Call to action** from the profile goes before the hashtags (on Instagram it can be combined with "link in bio"),
- only facts from the sources and the report.
